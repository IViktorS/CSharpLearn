# 1.1 — Value types vs reference types

## Суть
- **Value type (значимый тип)** — переменная хранит **само значение**. `struct`, все числовые (`int`, `double`, `bool`), `char`, `enum`, `DateTime`.
- **Reference type (ссылочный тип)** — переменная хранит **ссылку** на объект. `class`, `interface`, массивы, `string`, делегаты.

## Что происходит при присваивании/передаче
- Значимый тип → копируется **само значение** (независимая копия).
- Ссылочный тип → копируется **ссылка** (обе переменные смотрят на один объект).

## Передача в метод
- `struct` в метод → метод получает **копию**, изменения в исходник не попадают.
- `class` в метод → метод получает копию **ссылки**, но она указывает на тот же объект → изменения **содержимого** видны снаружи.
- Массив (`int[]`) — ссылочный тип: `DoubleAll(arr)` меняет исходный массив.

## Строки — особый случай
`string` — ссылочный тип, но **иммутабельный**. `s = s + "!!!"` создаёт **новую** строку, исходная не меняется. Поэтому `TryAppend(string s)` не влияет на строку снаружи.

Механика «копия значения vs копия ссылки» — фундамент, на котором стоят темы 1.2–1.4, 1.11, 1.12.
