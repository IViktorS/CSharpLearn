# 1.6 — Свойства (properties)

## Суть
Свойство — **умный доступ к данным**: снаружи как поле (`obj.Name`), внутри — методы `get`/`set` с возможной логикой. Даёт контроль (валидацию, уведомления), не меняя внешний синтаксис. Поле такого не умеет и ничем не защищено.

## value
`value` — **неявный параметр сеттера** (`set`/`init`), это присваиваемое значение (`obj.X = 5` → `value == 5`). В геттере `value` нет.

## Виды
- **Полное свойство** с backing-полем и логикой:
```csharp
private int _age;
public int Age { get => _age; set => _age = value < 0 ? throw new ... : value; }
```
- **Авто-свойство** `public int Age { get; set; }` — компилятор сам создаёт **скрытое backing-поле** (оно есть, просто не видно).
- **Управление доступом акцессоров**: `{ get; private set; }` (писать только внутри класса), `{ get; }` (только чтение).
- **`init`** — присвоить можно **только при создании** (конструктор/объектный инициализатор), потом только чтение (CS8852 при попытке изменить).
- **Вычисляемое**: `public string FullName => $"{First} {Last}";` — не хранит значение, считает при каждом обращении.
- **Expression-bodied** `=>` для однострочных акцессоров.

## Разграничения
- Авто-свойство всё равно имеет скрытое поле.
- `set` — менять когда угодно; `init` — только при создании.
- `get`-only задаётся в конструкторе/инлайн, но **не через объектный инициализатор** — для этого нужен `init`.
- Вычисляемое свойство отражает изменения зависимых полей на каждом `get`.
- `private set` = инкапсуляция: состояние меняется только внутри класса (CS0272 при попытке извне).
